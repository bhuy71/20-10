📸 THƯ MỤC ẢNH & NHẠC

1) Ảnh bạn gái hiện đang đặt trong thư mục images/.
   Muốn thêm/bớt ảnh, sửa mảng PHOTO_SOURCES trong file script.js.

2) Nhạc nền (tùy chọn) — đặt tên:
   - song.mp3
   Nếu không có file này thì web vẫn chạy, chỉ là không có nhạc.

Lưu ý: tên file phải viết thường, đúng chính tả, đuôi .jpg và .mp3.
